Dokumentasi Resmi Bahasa Ku

Bahasa Ku adalah bahasa pemrograman edukatif modern bertingkat tinggi dengan sintaksis bahasa Indonesia yang dirancang di atas arsitektur bahasa Go (Golang). Bahasa Ku memungkinkan pengembang, pelajar, maupun pemula untuk mempelajari konsep pemrograman modern—seperti konkurensi (Ku-routine), kanal, closures, manipulasi memori terstruktur, hingga web server—secara intuitif.

Pernyataan Etika & Sumber Inspirasi: Bahasa Ku terinspirasi oleh kesederhanaan desain arsitektur Google Go (The Go Authors / Google LLC). Bahasa Ku adalah proyek edukasi terbuka independen dan didistribusikan di bawah lisensi MIT.

Instalasi & Toolchain CLI

Bahasa Ku dapat dipasang secara langsung menggunakan satu perintah terminal otomatis di Windows (PowerShell):

Atau unduh biner langsung untuk Windows, Linux, maupun macOS dari Halaman Rilis GitHub.

Struktur Program Dasar, Inisiasi & Aturan Ekspor

Setiap program Bahasa Ku diawali dengan deklarasi paket dan impor pustaka, diikuti fungsi inisialisasi opsional fungsi inisiasi() yang otomatis berjalan lebih awal, dan fungsi entri utama fungsi utama():

paket utama

pakai "cetak"

// Berjalan otomatis lebih dulu sebelum utama() (mirip func init() di Go)
fungsi inisiasi() {
    cetak.tulis("Menyiapkan konfigurasi awal...")
}

fungsi utama() {
    cetak.tulis("Halo dari Bahasa Ku!")
}

Aturan Ekspor Paket (Kapitalisasi ala Go)

Ketika Anda mengimpor berkas modul lain melalui pakai "./helper.ku":

  • Simbol yang diawali Huruf Kapital (misal: HitungNilai, Versi) otomatis Publik & Terekspor ke paket pemanggil.
  • Simbol yang diawali huruf kecil (misal: rahasiaInternal, bantu()) bersifat Privat hanya di modul tersebut.

Bagian 2: Sintaksis & Fondasi Bahasa

Aturan dasar penulisan kode, deklarasi variabel, percabangan, fungsi, dan penanganan galat.

Variabel & Tipe Data

Bahasa Ku mendukung deklarasi variabel dinamis dan konstanta tetap:

paket utama

pakai "cetak"

fungsi utama() {
    // Deklarasi standar
    var nama = "Budi"
    
    // Inisialisasi cepat
    umur := 25
    tinggi := 175.5
    aktif := benar // boolean: benar / salah
    
    // Konstanta
    tetap PI = 3.14159
    
    // Nilai kosong
    var data = kosong // atau nihil

    cetak.tulis(nama, umur, tinggi, aktif, PI)
}

Array (Larik) & Map (Kamus)

// Larik (Array)
var buah = ["Apel", "Mangga", "Jeruk"]
tambah(buah, "Pisang")

// Slicing Larik
var sub = buah[1:3] // Mengambil indeks 1 hingga 2

hapus(profil, "pekerjaan")

Percabangan (Kondisi)

1. Jika / Lainnya (`if` / `else`)

jika nilai >= 85 {
    cetak.tulis("Predikat: A")
} lainnya jika nilai >= 70 {
    cetak.tulis("Predikat: B")
} lainnya {
    cetak.tulis("Predikat: C")
}

2. Pilih / Kasus (`switch` / `case`)

pilih peran {
    kasus "admin":
        cetak.tulis("Akses penuh sistem")
    kasus "editor", "penulis":
        cetak.tulis("Akses tulis konten")
    bawaan:
        cetak.tulis("Akses pengunjung biasa")
}

Perulangan (`untuk`)

1. Perulangan Standar Tiga Bagian

untuk i := 0; i < 5; i++ {
    cetak.tulis("Indeks:", i)
}

2. Perulangan Koleksi (`untuk ... dalam`)

var warna = ["Merah", "Hijau", "Biru"]
untuk idx, item dalam warna {
    cetak.tulis(idx, ":", item)
}

// Menghiraukan indeks dengan blank identifier '_'
untuk _, item dalam warna {
    cetak.tulis(item)
}

3. Perulangan Kondisional (While-style)

angka := 1
untuk angka <= 10 {
    angka += 2
}

4. Kontrol Perulangan (`henti` / `berhenti` & `lanjut`)

untuk i := 0; i < 10; i++ {
    jika i == 3 {
        lanjut // Lewati iterasi saat i bernilai 3
    }
    jika i == 7 {
        berhenti // Hentikan perulangan sepenuhnya saat i bernilai 7 (alias: henti)
    }
    cetak.tulis("Nilai:", i)
}

Fungsi, Multi-Return & Closure

1. Pengembalian Nilai Ganda (Multiple Return Values)

fungsi bagi(pembilang, penyebut) {
    jika penyebut == 0 {
        kembalikan 0, "Pembagian dengan nol dilarang!"
    }
    kembalikan pembilang / penyebut, kosong
}

// Pemanggilan
hasil, galat := bagi(10, 2)
jika galat != kosong {
    cetak.tulis("Error:", galat)
} lainnya {
    cetak.tulis("Hasil:", hasil)
}

2. Variadic Parameters & Fungsi Anonim (Closure)

fungsi jumlahkanSemua(...angka) {
    total := 0
    untuk _, n dalam angka {
        total += n
    }
    kembalikan total
}

// Fungsi Anonim / Lambda
var kuadrat = fungsi(x) {
    kembalikan x * x
}
cetak.tulis("Hasil kuadrat 5:", kuadrat(5))

Struktur (Struct), Method Receivers & Komposisi Embedding

tipe Persegi struktur {
    panjang,
    lebar
}

// Method receiver untuk struct Persegi
fungsi (p Persegi) luas() {
    kembalikan p.panjang * p.lebar
}

// Komposisi Struct Embedding ala Go (Field & Method Promosi Otomatis)
tipe KotakWarna struktur {
    bentuk Persegi // embedding
    warna
}

fungsi utama() {
    var k = KotakWarna({
        "warna": "Merah",
        "bentuk": Persegi({"panjang": 10, "lebar": 5})
    })

    // Field dan method Persegi otomatis dipromosikan:
    cetak.tulis("Warna:", k.warna)
    cetak.tulis("Panjang (promosi):", k.panjang)
    cetak.tulis("Luas (promosi method):", k.luas())
}

Penanganan Galat (`coba - tangkap - akhirnya` & `panik - pulih`)

1. Blok Eksepsi Terstruktur (`coba`, `tangkap`, `akhirnya`)

Bahasa Ku menyediakan sintaks penanganan galat modern yang ramah pengguna:

coba {
    cetak.tulis("Membaca berkas konfigurasi...")
    var isi = berkas.baca("konfig-rahasia.json")
    jika isi == kosong {
        panik("Berkas konfigurasi tidak ditemukan!")
    }
} tangkap (galat) {
    cetak.tulis("⚠️ Terjadi kesalahan tertangkap:", galat)
} akhirnya {
    cetak.tulis("✔️ Blok akhirnya selalu dijalankan untuk pembersihan aset.")
}

2. Panik & Pulih Tingkat Rendah (`panik` & `pulih`)

Mekanisme penanganan eksepsi bawaan setara Go panic dan recover menggunakan tunda:

fungsi prosesData() {
    tunda fungsi() {
        var err = pulih()
        jika err != kosong {
            cetak.tulis("Sistem pulih dari insiden:", err)
        }
    }()

    cetak.tulis("Memulai proses...")
    panik("Koneksi terputus mendadak!")
    cetak.tulis("Baris ini tidak akan dieksekusi")
}

Bagian 3: Konkurensi & Sinkronisasi

Manajemen proses paralel multi-threading ringan via Ku-routine, Kanal data, dan kunci Mutex.

Konkurensi (`ku`) & Kanal (`kanal`)

Jalankan pekerjaan paralel ringan menggunakan kata kunci ku dan komunikasikan data dengan aman menggunakan kanal:

paket utama

pakai "cetak"
pakai "kanal"
pakai "sistem"

fungsi pekerja(pipa) {
    sistem.tidur(500) // Istirahat 500 milidetik
    pipa.kirim("Laporan Selesai")
}

fungsi utama() {
    // Membuat kanal berkapasitas 1
    var pipa = kanal.buat(1)

    // Luncurkan Ku-routine
    ku pekerja(pipa)

    // Menerima data secara non-blocking
    var pesan, berhasil = pipa.terimaDenganWaktu(1000)
    jika berhasil {
        cetak.tulis("Pesan diterima:", pesan)
    }
}

Sinkronisasi Kelompok Tunggu (`kelompokTunggu`)

var kt = sistem.kelompokTunggu()

untuk i := 1; i <= 3; i++ {
    kt.tambah(1)
    ku fungsi(id) {
        tunda kt.selesai()
        cetak.tulis("Tugas pekerja selesai:", id)
    }(i)
}

kt.tunggu() // Menunggu hingga ketiga tugas selesai
cetak.tulis("Semua tugas tuntas!")

2. Sinkronisasi Kunci Mutex & RWMutex (`sistem.kunci`, `sistem.kunciBacaTulis`)

Mencegah tabrakan balapan data (race conditions) saat multi-routine memodifikasi memori bersama:

// 1. Mutex Eksklusif Standar
var k = sistem.kunci()
k.kunci()
// operasi kritis...
k.buka()

// 2. RWMutex (Kunci Baca Bersama & Kunci Tulis Eksklusif ala Go)
var rw = sistem.kunciBacaTulis()
rw.kunciBaca() // Banyak goroutine bisa membaca serentak
// membaca data...
rw.bukaBaca()

rw.kunci() // Kunci eksklusif untuk menulis
// memodifikasi data...
rw.buka()

3. Modul `atomik` (Operasi Lock-Free Concurrency)

Operasi paralel berkecepatan tinggi tanpa overhead penguncian mutex (berbasis sync/atomic):

var counter = 0
atomik.tambah(counter, 1)  // atomic.AddInt64
var val = atomik.baca(counter) // atomic.LoadInt64
atomik.tukar(counter, 1, 10)  // atomic.CompareAndSwapInt64

4. Modul `konteks` (Manajemen Batas Waktu & Pembatalan)

Pengendalian siklus hidup operasi konkurensi (ala context.Context):

var ctx, batal = konteks.denganBatasWaktu(1000) // batas waktu 1 detik
jika ctx.apakahBatal() {
    cetak.tulis("Operasi dibatalkan:", ctx.galat())
}
batal() // Batalkan secara manual kapan saja

5. Saluran Multiplexing (`kanal.pilih`)

Mendengarkan beberapa kanal sekaligus atau menggunakan fallback non-blocking (ala select di Go):

kanal.pilih({
    "kanal": ch1,
    "aksi": fungsi(pesan) { cetak.tulis("Dari ch1:", pesan) }
}, {
    "bawaan": fungsi() { cetak.tulis("Kanal belum siap") }
})

db.eksekusi("INSERT INTO produk (nama, harga) VALUES ('Kopi Ku', 15000);")

var daftar = db.kueri("SELECT id, nama, harga FROM produk")
cetak.tulis("Daftar produk:", daftar)
db.tutup()

// 2. Basis Data MySQL Terpusat
var mysqlDb = basisdata.sambung("mysql", "root:kata_sandi@tcp(127.0.0.1:3306)/db_ku")
jika mysqlDb["terhubung"] {
    cetak.tulis("Koneksi MySQL aktif!")
}

Modul `desktop` / `jendela` (GUI Desktop & Dialog Native)

Pengembangan aplikasi GUI desktop mandiri tanpa CGO dan kotak dialog sistem operasi asli:

FungsiDeskripsi
desktop.pesan(judul, pesan, [tipe])Menampilkan dialog pesan native OS (pilihan tipe: "info", "peringatan", "galat", "tanya")
desktop.pilihBerkas([judul], [filter])Membuka file dialog explorer native untuk memilih berkas fisik
desktop.pilihFolder([judul])Membuka folder browser dialog native untuk memilih direktori kerja
desktop.salinTeks(teks)Menyalin teks string langsung ke Papan Klip (Clipboard) sistem operasi
desktop.bacaKlip()Membaca teks yang sedang tersimpan di Papan Klip (Clipboard) sistem operasi
desktop.buka(opsi)Membuka jendela GUI webview desktop independen (mendukung judul, url, konten HTML, lebar, tinggi)
 
// 1. Kotak Dialog Native
desktop.pesan("Pemberitahuan", "Aplikasi berhasil diinstal!", "info")
desktop.pesan("Peringatan", "Koneksi database terputus", "peringatan")

// 2. Pemilih Berkas & Folder Native OS
var file = desktop.pilihBerkas("Pilih Laporan CSV", "Berkas CSV (*.csv)|*.csv")
cetak.tulis("Berkas dipilih:", file)

var folder = desktop.pilihFolder("Pilih Folder Backup")
cetak.tulis("Folder dipilih:", folder)

// 3. Jendela Desktop GUI Mandiri (App Mode)
desktop.buka({
    "judul": "Aplikasi Kasir Ku",
    "lebar": 1024,
    "tinggi": 720,
    "url": "http://localhost:8080" // atau konten HTML langsung
})
